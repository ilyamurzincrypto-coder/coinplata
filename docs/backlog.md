## Решить судьбу «International Office»

**Заведено:** 2026-08-27, при подготовке Экрана 4 «Счета · Крипто».
**Переформулировано:** 2026-08-27 по дельте эталона r6.
**Статус:** открыта, решение за владельцем. Из PR Экрана 4 убрана —
данные не трогаем, офис не активируем, кошелёк не перепривязываем.

**Что уже НЕ является проблемой UI.** Ревизия 6 эталона закрыла
презентационную часть: группы строятся по фактическому офису кошелька,
включая неактивные, и «International Office» показывается обычной группой
с оранжевой пометкой «офис неактивен · кошельки вне городов». Группа
«Без офиса» из макета убрана — она утверждала то, чего в данных нет.
Открытым остаётся только вопрос учёта: чем этот офис должен быть.

**Что на самом деле в данных** (`public.accounts`, прод, проверено SQL):

| поле | значение |
|---|---|
| id | `0fb6b363-dec9-47a4-89ff-c77b2ca3ca99` |
| name | WW-135 (kit out) |
| network / currency | TRC20 / USDT |
| address | `TYtC1HoczFTciw1Pp6c5m2vR6by8W1j9nd` |
| office_id | `63edef46-a114-4c98-9a38-497864ca1900` |
| aegis_wallet_id | `cmrx8r0ol0kok6mx5xdq8ndgn` |
| active | true |

То есть **`office_id` не пустой**. Формулировка «кошелёк не привязан» неточна:
он привязан к офису `63edef46…` = **«International Office» (city Worldwide)**,
у которого `active = false` и `coinpoint_office_code = null`. UI строит группы
по активным офисам, неактивный в список не попадает — и кошелёк проваливается
в «Без офиса».

**Вопрос владельцу:** чем должен быть «International Office» в учёте?

1. Легитимный контейнер для кошельков вне городов — тогда его стоит
   активировать (`active = true`) и, возможно, выдать
   `coinpoint_office_code`, чтобы он перестал быть исключением в других
   местах, где список офисов фильтруется по активным.
2. Технический артефакт — тогда WW-135 перепривязать к реальному офису,
   а сам офис оставить выключенным.

Влияет не только на ведомость: по активным офисам фильтруются и другие
экраны, поэтому выбор лучше сделать один раз и явно. Пока решения нет,
ведомость показывает офис как есть — это честно и ничего не искажает.
